Все авторизованные клиентские маршруты требуют `Authorization: Bearer <jwt>` пользовательской сессии устройства (токены портала разработчиков с `scope: "developer_portal"` здесь отклоняются). Передавайте `X-Api-Id` (`1..6` или кастомный `>= 100000` в паре с `X-Api-Hash`). Машиночитаемая спецификация доступна в [`/openapi.json`](/openapi.json).
