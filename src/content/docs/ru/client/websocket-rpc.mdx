Подключитесь к потоку WebSocket, передав JWT и идентификатор устройства в строке запроса или заголовках:

```text
wss://api.theaver.app/api/ws?token=<jwt_token>&device_id=<device_id>
```

Нативные клиенты также могут передавать `Authorization: Bearer <jwt_token>` и `X-Device-ID` при handshake (браузеры — через `Sec-WebSocket-Protocol`). Сразу после соединения сервер присылает `{ "type": "connected", "user_id": "...", "timestamp": "..." }`.

## Формат клиентских RPC-вызовов (`Client → Server`)

Параметры вызова передаются внутри вложенного объекта `data`, а поле `req_id` сопоставляет ответ с конкретным запросом:

```json
{
  "type": "send_message",
  "req_id": "req-101",
  "data": {
    "chat_id": 849201432,
    "content": "Привет через WebSocket RPC",
    "local_id": "client-uuid-991",
    "reply_to_message_id": null
  }
}
```

Если передан `req_id`, сервер гарантированно отвечает либо `{ "type": "rpc_result", "req_id": "req-101", "ok": true, "result": { ... }, "timestamp": "..." }`, либо `{ "type": "rpc_error", "req_id": "req-101", "ok": false, "error_code": 429, "error": "SLOWMODE_WAIT", "description": "...", "parameters": { "retry_after": 12 } }`. Неизвестный `type` возвращает `UNKNOWN_METHOD`.

### Поддерживаемые методы RPC

| `type` | Ключевые поля в `data` | Поведение |
|---|---|---|
| `ping` | опционально `req_id` | Проверка соединения; отвечает `pong` |
| `client_state` | Статус активности приложения | Управляет подавлением фоновых push-уведомлений |
| `active_chat` | `chat_id` (`0` при сворачивании) | Подавляет уведомления для открытого диалога |
| `typing` | `chat_id`, `action` | `typing`, `record_voice`, `record_round`, `uploading_photo`, `uploading_video`, `uploading_file`, `uploading_audio`, `choosing_sticker`, `stop` |
| `emoji_interaction` | `chat_id`, `message_id`, `emoji` | Синхронизирует полноэкранные эффекты нажатий эмодзи |
| `send_message` | `chat_id`, `content`, `local_id`, `file_url`, `message_type`, `topic_id`, `is_round`, `is_view_once`, `ttl_seconds`, `send_as_anonymous` | Идемпотентная отправка; возвращает `result.message` (или `{ deduplicated: true, message }`) |
| `read_history` / `mark_read` | `chat_id`, `max_id` | Сдвигает High-Water Mark и пересчитывает непрочитанное |
| `callback_query` | Данные inline-кнопки бота | Вызывает callback бота и возвращает всплывающий ответ или URL |
| `call.*` | `call_id`, потоки, SDP/ICE | `call.start`, `call.accept`, `call.decline`, `call.leave`, `call.transfer_device`, `call.update_state`, `call.stream.*`, `call.signal` |

## События от сервера (`Server → Client`)

Все события приходят в формате `{ "type": "<event_type>", ... }` и параллельно записываются в журнал `usn` для дозагрузки через `/api/updates?since_usn=...`:

| Тип события | Когда возникает |
|---|---|
| `new_message`, `message_edited`, `message_deleted`, `message_burned` | Новое, изменённое, удалённое или сгоревшее по TTL сообщение |
| `message_read`, `unread_count_updated`, `unread_badges_updated`, `message_listened` | Изменение указателей High-Water Mark, бейджей или прослушивания голосовых |
| `message_reaction_updated`, `message_pinned`, `message_unpinned`, `message_views_updated`, `post_comments_updated` | Реакции, закрепы, просмотры в канале или счётчик комментариев |
| `new_chat`, `chat_update`, `chat_deleted`, `chat_archive_updated`, `chat_settings_updated`, `chat_appearance_updated`, `chat_auto_delete_updated`, `chat_unread_marked`, `forum_topic_updated` | Создание или изменение чата, темы форума, архива и оформления |
| `member_joined`, `member_updated`, `join_requests_updated`, `scheduled_messages_updated` | Состав участников, заявки на вступление или очередь отложки |
| `draft_updated`, `typing`, `emoji_interaction`, `screenshot_taken` | Облачный черновик, набор текста, эффекты эмодзи, уведомление о скриншоте |
| `user_online`, `user_offline`, `user_status`, `user_avatar_updated`, `user_appearance_updated`, `contact_updated`, `contact_deleted` | Статусы онлайна, аватары и контакты |
| `session_terminated`, `app_update_available` | Отзыв текущей сессии или выход новой версии |
