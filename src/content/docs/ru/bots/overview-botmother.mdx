Бэкенд Theaver реализует **Telegram-совместимый Bot API (v7.x)** вместе со встроенным системным ботом **`@BotMother`** (`id = 100000001`) и его графическим Mini App для управления ботами.

## Создание первого бота

1. Откройте диалог с **`@BotMother`** в Theaver.
2. Отправьте команду `/newbot`.
3. Введите отображаемое имя бота и уникальный username, оканчивающийся на `bot` (например, `release_notify_bot`).
4. Сохраните выданный токен вида `<bot_id>:<secret>` в переменной окружения.

## Команды `@BotMother`

| Команда | Назначение |
|---|---|
| `/newbot` | Пошаговое создание бота и выпуск токена |
| `/mybots` | Интерактивное меню управления вашими ботами |
| `/token` / `/revoke` | Просмотр или перевыпуск токена API |
| `/setname` | Изменение отображаемого имени бота |
| `/setdescription` | Полное описание, видимое до нажатия «Старт» |
| `/setabouttext` | Краткое описание в профиле бота |
| `/setcommands` | Меню команд (`command - Описание`) |
| `/setjoingroups` | Разрешить или запретить добавление бота в группы |
| `/setprivacy` | Режим приватности в группах (`Enable` — только команды и упоминания; `Disable` — все сообщения) |
| `/setinline` | Включение inline-запросов (`@bot запрос`) |
| `/deletebot` | Удаление бота |

## Базовый URL Bot API

Все методы принимают `GET` или `POST` запросы с `application/json`, `application/x-www-form-urlencoded`, `multipart/form-data` или параметрами строки запроса по адресу:

```text
https://api.theaver.app/bot<token>/<method>
```

Также поддерживается маршрут `/api/bot<token>/<method>`, а файлы, полученные через `getFile`, скачиваются по `/file/bot<token>/<file_path>`.

<Callout type="warning" title="Храните токен в секрете">
  Никогда не публикуйте `<bot_id>:<secret>` в открытых репозиториях или клиентском JavaScript-коде Mini App. При компрометации немедленно перевыпустите токен командой `/revoke` в `@BotMother`.
</Callout>
