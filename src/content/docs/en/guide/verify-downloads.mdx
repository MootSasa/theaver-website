Every official Theaver build is published with cryptographic verification metadata. Before installing an archive or executable downloaded outside a package manager, verify its integrity locally.

## Public signing keys

You can download the official public keys directly from this website or inspect them inside the open-source [`theaver-frontend`](https://github.com/MootSasa/theaver-frontend) repository under `signing/`:

- Linux GPG release public key: [`/signing/theaver-release-public.asc`](/signing/theaver-release-public.asc)
- Windows code-signing root certificate: [`/signing/theaver-windows-root.cer`](/signing/theaver-windows-root.cer)

## Checking SHA-256 checksums

Each artifact listed on [Downloads](/downloads) and in the in-app updater displays its exact `SHA-256` digest. Compute the local hash and compare both strings character for character:

<CodeTabs tabs={['Linux / macOS', 'Windows (PowerShell)']}>
```bash
shasum -a 256 theaver-v1.20.3-beta-linux-x64.tar.gz
# or on Linux:
sha256sum theaver-v1.20.3-beta-linux-x64.tar.gz
```

```powershell
Get-FileHash .\theaver-v1.20.3-beta-windows-x64-setup.exe -Algorithm SHA256
```
</CodeTabs>

## Verifying Linux archives with GPG

Linux `.tar.gz` bundles ship alongside a matching `.tar.gz.asc` detached signature:

```bash
curl -fsSLO https://theaver.app/signing/theaver-release-public.asc
gpg --import theaver-release-public.asc
gpg --verify theaver-v1.20.3-beta-linux-x64.tar.gz.asc theaver-v1.20.3-beta-linux-x64.tar.gz
```

Look for `Good signature` from the imported Theaver release key.

## Verifying Windows installers

Windows builds (`.exe` installer and runner binaries) are signed using Authenticode. If you want to verify or trust the publisher root certificate explicitly on Windows:

```powershell
curl -fsSLO https://theaver.app/signing/theaver-windows-root.cer
Get-AuthenticodeSignature .\theaver-v1.20.3-beta-windows-x64-setup.exe
```

<Callout type="warning" title="Never skip checksum verification on untrusted mirrors">
  Always download Theaver installers from `theaver.app`, `storage.theaver.app`, or the official GitHub Releases page (`MootSasa/theaver-frontend`).
</Callout>
