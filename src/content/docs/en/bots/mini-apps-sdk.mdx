Theaver Mini Apps (v8.0) run HTML5/JS applications inside native WebViews on mobile, desktop, and browser clients using the `window.Telegram.WebApp` JavaScript bridge.

## Registering a Mini App

You can bind a Main Mini App URL or named Short Name Mini App to your bot via `@BotMother` (or the `@BotMother` Studio Mini App) and expose it through:

- Bot menu button (`setChatMenuButton` with `{ "type": "web_app", "text": "Open App", "web_app": { "url": "https://..." } }`)
- Inline keyboard `web_app` buttons
- Direct deep links to `https://theaver.app/u/<bot_username>?startapp=<param>`

## Client JS Bridge (`window.Telegram.WebApp`)

Include the standard script or inspect `window.Telegram.WebApp` directly on load:

```js
const tg = window.Telegram.WebApp;
tg.ready();
tg.expand();

// Adapt styling to active Theaver user theme
document.body.style.backgroundColor = tg.themeParams.bg_color;
document.body.style.color = tg.themeParams.text_color;

// Configure persistent action button
tg.MainButton.setText("Save Settings");
tg.MainButton.show();
tg.MainButton.onClick(() => {
  tg.HapticFeedback.impactOccurred("medium");
  tg.sendData(JSON.stringify({ action: "saved" }));
});
```

### Supported Mini App v8 capabilities

- **Lifecycle & HUD insets:** `ready()`, `expand()`, `close()`, `safeAreaInset`, `contentSafeAreaInset`, and live `safe_area_changed` / `content_safe_area_changed` events.
- **Native controls:** `MainButton`, `SecondaryButton`, `BackButton`, `SettingsButton`.
- **Device & Cloud APIs:** `CloudStorage` (per-bot, per-user key-value storage), `HapticFeedback`, `showScanQrPopup`, and `requestWriteAccess`.

## Verifying `initData` on your backend

Never trust `initDataUnsafe` on your server. Always validate the signed `initData` query string using `HMAC-SHA256` with key `HMAC_SHA256("WebAppData", bot_token)`:

```python
import hashlib
import hmac
from urllib.parse import parse_qsl

def verify_init_data(init_data: str, bot_token: str) -> dict[str, str] | None:
    pairs = dict(parse_qsl(init_data, keep_blank_values=True))
    received_hash = pairs.pop("hash", None)
    if not received_hash:
        return None

    data_check_string = "\n".join(f"{k}={v}" for k, v in sorted(pairs.items()))
    secret_key = hmac.new(b"WebAppData", bot_token.encode(), hashlib.sha256).digest()
    expected_hash = hmac.new(secret_key, data_check_string.encode(), hashlib.sha256).hexdigest()

    if not hmac.compare_digest(expected_hash, received_hash):
        return None
    return pairs
```

<Callout type="tip" title="Validate auth_date freshness">
  Always check that `int(time.time()) - int(pairs["auth_date"])` falls within an acceptable window (such as 3600 seconds) to prevent replay of captured `initData` payloads.
</Callout>
