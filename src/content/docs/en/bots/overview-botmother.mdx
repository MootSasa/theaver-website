Theaver implements an **HTTP Bot API (v7.x)** alongside the built-in system bot **`@BotMother`** (`id = 100000001`) and its graphical Bot Studio Mini App for managing both bots and third-party client credentials. For compatibility aliases when porting existing bots, see [Migrating Existing Bots](/docs/bots/migrating-from-telegram).

## Creating your first bot

1. Open a conversation with **`@BotMother`** in Theaver.
2. Send `/newbot`.
3. Provide a display name and a unique username ending with `bot` (for example, `release_notify_bot`).
4. Save the returned `<bot_id>:<secret>` token inside an environment variable.

## `@BotMother` commands

| Command | Purpose |
|---|---|
| `/newbot` | Interactive wizard that creates a bot and mints an API token |
| `/mybots` | Interactive management panel for your bots and Mini Apps |
| `/token` / `/revoke` | View or rotate a bot token immediately |
| `/setname` | Update the bot display name |
| `/setdescription` | Long description shown before starting the bot |
| `/setabouttext` | Short bio displayed on the bot profile |
| `/setcommands` | Configure command menu (`command - Description`) |
| `/setjoingroups` | Allow or disallow adding the bot to groups |
| `/setprivacy` | Toggle group privacy (`Enable`: commands/mentions only; `Disable`: all messages) |
| `/setinline` | Enable inline queries (`@bot query`) |
| `/deletebot` | Permanently delete a bot |
| `/newclient` | Register a third-party client app (`api_id` + `api_hash`) |
| `/myclients` | Manage custom client apps, quotas, and statuses |
| `/revokeclient` | Revoke an existing custom `api_id` credential pair |

You can also open the **Client Apps** tab inside `@BotMother` Studio or use the web console at [`/developers/apps`](/developers/apps).

## Base Bot API endpoint

All methods accept `GET` or `POST` requests with `application/json`, `application/x-www-form-urlencoded`, `multipart/form-data`, or query parameters at:

```text
https://api.theaver.app/bot<token>/<method>
```

Routes are also aliased under `/api/bot<token>/<method>`, and media files returned by `getFile` download via `/file/bot<token>/<file_path>`.

<Callout type="warning" title="Keep tokens confidential">
  Never embed `<bot_id>:<secret>` in client-side Mini App JavaScript or commit it to public repositories. Rotate leaked tokens immediately with `/revoke` inside `@BotMother`.
</Callout>
