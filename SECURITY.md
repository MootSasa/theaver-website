# Security Policy

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in public issues or community chats before a fix ships.

Send reports privately using either channel:
- **GitHub Security Advisories:** [Open a private advisory](https://github.com/MootSasa/theaver-website/security/advisories/new) (or use the main [client security advisories](https://github.com/MootSasa/theaver-frontend/security/advisories/new) if the finding relates to the app)
- **Email:** [security@theaver.app](mailto:security@theaver.app)

Please include steps to reproduce, the affected page or endpoint, and potential impact. We aim to respond within 72 hours.

## Standards & Public Policy

- Web security overview: [`theaver.app/security`](https://theaver.app/security)
- Machine-readable RFC 9116 file: [`theaver.app/.well-known/security.txt`](https://theaver.app/.well-known/security.txt)
