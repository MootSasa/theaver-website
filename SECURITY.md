# Security Policy / Политика безопасности

## English

### Reporting a Vulnerability

Please do not disclose security issues in public issues or community chats before a fix ships.

Send reports privately using either channel:

- GitHub Security tab: [github.com/MootSasa/theaver-website/security](https://github.com/MootSasa/theaver-website/security) (click **Report a vulnerability**), or [github.com/MootSasa/theaver-frontend/security](https://github.com/MootSasa/theaver-frontend/security) if the finding concerns the client app
- Email: [security@theaver.app](mailto:security@theaver.app)

Include reproduction steps, the affected URL or endpoint, and the potential impact. We aim to acknowledge reports within 72 hours.

### Public Policy Endpoints

- Web security overview: [theaver.app/security](https://theaver.app/security)
- Machine-readable RFC 9116 policy: [theaver.app/.well-known/security.txt](https://theaver.app/.well-known/security.txt)

## Русский

### Как сообщить об уязвимости

Не публикуйте детали найденных уязвимостей в открытых Issue или чатах до выхода исправления.

Передайте отчёт приватно через любой из каналов:

- Вкладка безопасности на GitHub: [github.com/MootSasa/theaver-website/security](https://github.com/MootSasa/theaver-website/security) (кнопка **Report a vulnerability**) либо [github.com/MootSasa/theaver-frontend/security](https://github.com/MootSasa/theaver-frontend/security), если проблема относится к клиенту
- Почта: [security@theaver.app](mailto:security@theaver.app)

Опишите шаги воспроизведения, затронутую страницу или эндпоинт и возможный эффект. Мы стараемся отвечать в течение 72 часов.

### Открытые материалы

- Раздел безопасности на русском: [theaver.app/ru/security](https://theaver.app/ru/security)
- Файл стандарта RFC 9116: [theaver.app/.well-known/security.txt](https://theaver.app/.well-known/security.txt)
